# Included themes

`icmc.yml` follows the ICMC/USP visual identity manual, second edition, May 2016. Its five documented RGB colors are `#F6AA41`, `#72849D`, `#C6CEDA`, `#727376`, and `#DCD6CD`. The header pairs the manual's light blue with a transparent, blue-only institutional mark and uses no orange; orange remains a restrained body accent. The theme uses Droid Sans, one of the manual's open-source type recommendations.


Render the same source with the theme:

```bash
mdpresent examples/features.md -c themes/icmc.yml -o examples/output/features-icmc.pdf
```

The bundled fonts retain their upstream licenses in `themes/fonts/`.
